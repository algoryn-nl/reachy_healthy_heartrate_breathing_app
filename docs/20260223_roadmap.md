## Future Vision

### Handler Decomposition (complete)

All major concerns extracted from `_run_realtime_session()` into standalone, testable classes: IdlePolicy, LightOrchestrator, TranscriptHandler, ToolDispatcher, AudioRouter. The event loop is now a ~80-line thin router. See `docs/plans/2026-02-23-decompose-session-design.md`.

### Robustness

- Non-blocking tool dispatch with `asyncio.create_task()` + `Semaphore(1)` + `wait_for()` timeout (complete)
- Protocol version mismatch now logged at WARNING; full handshake rejection TBD
- Graceful degradation when mmWave sensor disconnects mid-session

### Testing

- Integration tests for the async streaming loop with mock WebSocket
- Boundary condition tests for bio rate filtering (exact guard-rail values)
- File I/O error tests for LightOrchestrator persistence (corrupted JSON, permissions)

### Sensor Intelligence

- Multi-person tracking: use targets truncation flag, handle >1 target
- Use BIO state field for richer context (e.g., "user was moving during measurement")
