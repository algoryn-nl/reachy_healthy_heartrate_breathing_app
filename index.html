Reachy Mini App

Healthy Heartrate Breathing

A wellness-aware conversation app for the Reachy Mini robot. Uses mmWave radar to sense heart rate, breathing rate, and presence — so the robot can respond to how you're actually doing.

▶

Overview

What It Does

  • 💬
    Voice Conversations

    Real-time audio via the OpenAI Realtime API — the robot listens, speaks, and reacts with expressive head motion.

  • 💓
    Heart Rate & Breathing

    A 60 GHz mmWave radar measures heart rate and breathing rate without any wearable — contactless, from up to 1.5 m away.

  • 👁
    Presence Detection

    Detects up to 8 people in the room with position, range, and bearing. Knows when someone sits down, moves away, or is resting still.

  • 💡
    Proximity Sensing

    A lux sensor detects body occlusion — when someone is close, the robot adapts its conversational style accordingly.

The app runs on the Reachy Mini. It streams audio to OpenAI for conversation, reads radar and lux data over USB serial from the sensor module, and fuses everything into context-aware robot behavior — dances, expressions, head tracking, and health-aware dialogue.

Required Hardware

mmWave Sensor Module

This app requires a custom sensor assembly connected to the Reachy Mini via USB. The core component is the Seeed MR60BHA2 mmWave radar module.

Getting Started

Installation

Install from the Reachy Mini app store, or run locally:

uv sync
reachy-mini-daemon --sim          # in another terminal
healthy-heartrate-breathing       # headless console mode
healthy-heartrate-breathing --gradio  # or web UI

Requires an OpenAI API key for voice conversations. Set it via the web interface or OPENAI_API_KEY environment variable.
